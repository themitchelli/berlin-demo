# The Million Lives Experiment

<!-- FADE.md - Project context for AI coding agents. This file is READ-ONLY for agents. -->

## Project Overview

An interactive web page for a conference demonstration to actuaries. One million simulated people, shown as about 1,000 animated particles, age from a chosen starting age towards 120. A survival curve and the surviving population update live. A slider applies a mortality improvement and shows the baseline and improved scenarios side by side.

Users: a presenter on a projector, then anyone who opens the repo afterwards.
State: greenfield. Nothing exists yet.

**The one rule that matters:** the actuarial calculation is deterministic and lives in `src/engine/`. The particle animation is a picture of the engine's numbers. It never introduces randomness into survivor counts. A pretty picture is not evidence the model is right; the tests are.

**Tech Stack (fixed, do not substitute):**
- Language: JavaScript (ES modules), HTML, CSS. No TypeScript, no React, no bundler, no npm dependencies.
- Rendering: HTML5 Canvas for particles and the chart. No charting library.
- Tests: Node's built-in test runner (`node --test`). No Jest, no Vitest.
- Data: `data/mortality.csv`, generated by `tools/generate-table.mjs`, committed.
- Serving: any static server, e.g. `python3 -m http.server 8080` or `npx serve`. The page must also work opened directly as a file where fetch of the CSV is allowed; if not, document the server command.

Node 20 or later. Nothing else is installed.

## Coding Standards

- Plain ES modules with `export`/`import`. The engine must run in Node and in the browser unchanged.
- `camelCase` for functions and variables, `UPPER_SNAKE` for constants.
- Pure functions in `src/engine/`. No DOM access there.
- Tests in `tests/*.test.mjs`, one file per engine module.
- Commits: Conventional Commits (`feat:`, `fix:`, `chore:`, `test:`).
- Fractional survivor counts internally; round only for display.
- Terminal age convention: q(120) = 1. Everyone alive at 120 dies in that year. State this in the engine's module comment and in README.

## Architecture

```
index.html            page shell, loads src/app.mjs
src/engine/table.mjs  loads and validates the mortality table (ages 0-120, M and F)
src/engine/survival.mjs  survivors(l0, qx, startAge) -> array of lx by age; applyImprovement(qx, pct)
src/particles.mjs     particle field, DISPLAY ONLY, takes survivor counts from the engine
src/chart.mjs         survival curve on canvas, two series, current-age marker
src/app.mjs           wiring: controls, animation loop, stats
tools/generate-table.mjs  writes data/mortality.csv (deterministic Gompertz-Makeham)
tools/reference.py    independent Python check of a few survivor values, written without reading the JS
data/mortality.csv    the synthetic table
data/reference.json   expected lx at a few ages, produced by tools/reference.py
tests/                node --test
```

Formula: `l(x+1) = l(x) * (1 - q(x))`. Improvement: `qImproved(x) = (1 - pct) * q(x)`, pct between 0 and 0.30.

## Target Architecture

- Engine first, picture second. Every story that touches the engine ships with tests.
- The animation loop reads precomputed survivor arrays. It never recomputes mortality per frame.
- One global state object in `src/app.mjs`; modules receive what they need as arguments.

## Off-Limits

| Path | Reason |
|------|--------|
| `data/reference.json` | Produced by the independent Python check. Agents must not edit it to make tests pass. |
| `tools/reference.py` | Same. If a test disagrees with the reference, the engine is wrong until a human says otherwise. |

**If you need to modify an off-limits file:** stop and ask.

## Session Boundaries

Allowed: create and edit files anywhere except the off-limits paths; run `node --test`; run `node tools/generate-table.mjs`; commit on the current branch.
Never: add npm dependencies; add a build step; push; edit `.env`; mark a story `passes: true` without running its tests.

## Development Environment

- Run tests: `node --test`
- Regenerate the table: `node tools/generate-table.mjs`
- Serve: `python3 -m http.server 8080` then open `http://localhost:8080/`

## Additional Context

The audience are actuaries. They know survival curves. They will not forgive a wrong number but will forgive a plain design. Do the numbers first.
